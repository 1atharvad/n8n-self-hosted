## What's in this repo

<CardGrid stagger>
  <Card title="Workflow Automation" icon="rocket">
    n8n self-hosted — workflows covering video pipeline, schedule management, and media processing automation.
  </Card>
  <Card title="Media Processing API" icon="laptop">
    FastAPI service (`api/`) handling TTS, PowerPoint generation, video encoding, and shell execution — everything too heavy for n8n nodes.
  </Card>
  <Card title="Admin Panel" icon="setting">
    React + FastAPI operations dashboard. Manage env vars, view logs, restart containers, trigger deploys — no SSH needed.
  </Card>
  <Card title="Custom n8n Nodes" icon="puzzle">
    Two TypeScript nodes: `JsonVariables` (persistent key-value store) and `RemoteExecute` (shell commands via Media API).
  </Card>
</CardGrid>
